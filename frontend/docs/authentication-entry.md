# 登录入口与身份边界

## 企业登录

普通企业用户统一使用“企业登录”，凭据为企业编码、用户名和密码。界面中的“企业编码”对应服务端的 `tenant_code`（API 请求字段仍为 `tenantCode`），用于由控制面解析租户身份和数据库路由；它不是数据库名称，也不允许用户指定数据库连接信息。

企业管理员和普通员工共用企业登录入口，登录后的操作范围由企业内部角色和权限决定。

## 平台管理登录

平台运营管理员使用独立的“平台管理登录”入口。平台身份、认证 API、会话和权限与企业用户完全分离。企业登录页面在底部提供低强调度的“平台管理登录”链接；平台登录页面提供返回企业登录的链接。

平台管理员不能直接切换为企业用户身份，也不能通过企业登录会话访问平台管理功能。需要平台运维访问企业数据时，必须使用另行定义的受控授权机制，不得伪装成企业用户。

## 未登录页面行为

- 根路径默认进入独立全屏企业登录页。
- 登录页不渲染工作区顶部栏、标签、导航、账户菜单或工作区页脚。
- 未认证访问企业受保护路由时跳转企业登录。
- 未认证访问平台管理受保护路由时跳转平台管理登录。
- 两类登录页面都独立于已登录工作区布局。
