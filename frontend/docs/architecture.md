# ZTX 前端工程与工作区架构

## 依赖方向

```text
erp-web
  ├── metadata-renderer
  ├── business
  ├── api-client
  └── ui
       └── Reka UI / Lucide
design-tokens ──> ui / erp-web
test-utils ──> tests only
```

当前各包位于同一 pnpm Workspace，不单独发布或部署。目录用于职责隔离，不预设未来必须拆成独立服务。

## 工作区布局

- 顶部：品牌标识、工作区多标签；右侧仅全屏、通知和用户图标。
- 左侧第一级：平台模块入口。
- 左侧第二级：当前模块下的业务分类。
- 右侧浮层第三级：二级分类对应的具体功能入口。
- 主内容区：当前路由页面。

## 导航行为

1. 点击一级菜单切换模块并展示该模块的二级分类。
2. 桌面端悬停二级分类时，在右侧打开三级功能浮层；点击二级分类同样可以展开/收起。
3. 指针离开导航区域后延迟 220ms 关闭；指针移入三级浮层不会触发关闭。
4. 触屏端点击二级分类展开，不依赖 hover。
5. 三级功能点击后进入路由并打开/激活顶部工作区 Tab。
6. Escape 关闭浮层并将焦点还给二级菜单；方向键可切换二级分类和三级功能。
7. 不提供第四级菜单。

## 视觉 Token

使用暖色中性色、低饱和铜棕色作为强调色，避免灰蓝主色。布局采用适度紧凑的信息密度，减少无意义留白，不以大面积卡片和阴影装饰页面。
